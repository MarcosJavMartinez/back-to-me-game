## Variables locales

Copiar `.env.example` a `.env.local` y completar:

```bash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

`.env.local`, `.vercel`, `node_modules`, `.next`, `.test-dist` y `supabase/.temp` quedan fuera de Git.
